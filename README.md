# Digitalización-PartesTrabajo
Proyecto de la asignatura de Digitalización y Sostenibilidad de el grado superior DAW

# 📜 PROYECTO 4 – Digitalización de partes de trabajo

## 🏢 Contexto
Actualmente, los técnicos rellenan partes de trabajo en papel, los cuales a menudo se pierden o llegan con retraso a la oficina.

## 🎯 Objetivo
Sustituir el uso de papel por una aplicación de partes de trabajo digitales.

## ⚙️ Funcionalidades mínimas
- Crear parte de trabajo con los siguientes datos:
  - Cliente
  - Fecha
  - Horas trabajadas
- Descripción de las tareas realizadas.
- Estado del parte:
  - Pendiente
  - Enviado
  - Aprobado

## 🚀 Ampliaciones
- Firma digital simulada.
- Adjuntar fotografías.
- Envío automático al responsable.

## 🖼 Imagen de referencia
Formulario tipo móvil, con campos grandes y un botón destacado **"Enviar parte"**.
